# three-home · 擎天柱 OPTIMUS PRIME

一个能动的擎天柱：网页里能直接玩的 Three.js 演示版 + 正在建模的 Blender 精模版，两条线都在这个仓库里。

## 在线预览（GitHub Pages）

**https://zhaojjjjjj.github.io/three-home/**

打开即玩，就是下面的网页演示版。

## 网页演示版（已上线）

纯前端、零构建：根目录 `index.html` 就是本体，Three.js r186 在 `vendor/` 本地化，不依赖 CDN，离线可跑。

- **动作**：待机 / 行走 / 奔跑 / 挥手 / 出拳，按钮或空格触发，真铰链关节（髋 / 膝 / 肩 / 肘 / 颈）
- **移动**：`WASD` / 方向键走动转向，相机自动跟随（可关），速度滑杆
- **变形**：一键折叠成卡车（可开），再一键变回机器人
- **视角**：拖拽旋转、滚轮 / 双指缩放

造型是程序化零件拼装（装甲板、活塞、散热鳍片、螺栓阵列），PBR 漆面 + 影棚反射。它的上限也在这里：轮廓偏玩具感——这是下一条线要解决的问题。

## Blender 精模版（进行中）

目标：真人电影机甲感。Blender 参数化建模（真实倒角、曲面驾驶舱、分层装甲、暗色内骨架、程序化做旧）→ Cycles 渲染验形态 → 绑骨动画 → 导出 GLB 接回网页查看器。

- 建模脚本、工程文件说明和渲染图在 [`blender/`](blender/)，`build_optimus.py` 是源文件，`.blend` 与渲染图都是它的生成物
- 当前进度：主形已出图（全身 + 头部特写），材质 / 光照 / 内骨架成立；整体比例仍偏 G1，形态评审中

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 不能直接双击用 `file://` 打开：页面用了 ES 模块 + importmap，需要经 http 服务。
