# 擎天柱 · Three.js 能动演示版

用 Three.js 程序化拼出的方块风擎天柱，关节都是真铰链结构（髋 / 膝 / 肩 / 肘 / 颈），在浏览器里就能动起来。

造型元素：红色胸甲 + 双挡风玻璃、蓝色头盔与天线、银色烟囱、格栅腹、发光蓝眼、小腿轮子。

## 在线玩 / 本地跑

这是一个纯静态页面（`index.html`），Three.js r186 以 ES Module 方式从仓库内的 `vendor/` 目录加载（不依赖 CDN，离线也能跑）。因为用了 ES Module，**不能直接双击用 `file://` 打开**，需要一个静态服务器：

```bash
# 任选其一
npx serve .
python3 -m http.server 8000
```

然后打开 `http://localhost:8000`（端口以你用的工具为准）。

也可以开启 GitHub Pages（Settings → Pages → Deploy from branch `main` / root），之后通过 Pages 地址直接玩。

## 玩法

- **动作**：待机呼吸、行走、奔跑、挥手、出拳，点按钮切换，带平滑过渡
- **移动**：`W` / `↑` 前进，`S` / `↓` 后退，`A` `D` / `←` `→` 转向；手机上有屏幕方向键。行走 / 奔跑时按住前进键才会走，松开原地踏步
- **视角**：鼠标拖拽旋转、滚轮缩放；可开相机跟随，也可一键重置视角
- **速度**：滑杆调移动速度
- **变形**：点「变形」一键折叠成带货厢和六个轮子的卡车形态，能开着走，再点一次变回机器人

## 说明

- 本仓库是**演示版路线**：模型由 Three.js 代码用几何体拼装，没有用 Blender 建模，也没有外部 `.glb` 文件；变形是简化版插值折叠，不是零件级精确变形。
- 后续精细版路线：Blender 建模 + 绑骨 + K 帧动画 → 导出 `.glb` → Three.js 用 `GLTFLoader` + `AnimationMixer` 加载播放，`index.html` 的交互层（动作切换、移动、相机）可以基本复用。
- 个人学习演示用途，请勿商用或分发相关角色形象。
