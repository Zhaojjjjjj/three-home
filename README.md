# three-home · 擎天柱 OPTIMUS PRIME

一个能动的擎天柱 Three.js 演示：纯前端、零构建，仓库根目录的 `index.html` 就是本体（Three.js r186 在 `vendor/` 本地化，不依赖 CDN，离线可跑）。

## 在线预览（GitHub Pages）

**https://zhaojjjjjj.github.io/three-home/**

打开即玩：成型曲面装甲 + 梯形截面 + 英雄比例的擎天柱，PBR 金属漆面（红/蓝车漆 + 铬件 + 发光蓝眼），零件计数 12,800（网格 1,020，实例化渲染）。

## 玩法

- **动作**：待机 / 行走 / 奔跑 / 挥手 / 出拳，点按钮或按空格出拳，真铰链关节（髋/膝/肩/肘/颈）
- **移动**：`WASD` / 方向键走动转向；行走/奔跑时按住前进才走，松开原地踏步
- **变形**：一键折叠成卡车（可开），再一键变回机器人
- **视角**：拖拽旋转、滚轮/双指缩放，相机跟随开关、速度滑杆

## 本地运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 不能直接双击用 `file://` 打开：页面用了 ES 模块 + importmap，需要经 http 服务。

## 造型说明

- 参数化零件工厂生成：装甲板（弧度/倒角/收边）、活塞、齿轮、散热鳍片、通风阵列、螺栓铆钉、线束软管、轮胎花纹、手指关节
- 分区装配：头/胸/肩/臂/手/腰/腿/脚/背包逐区建模，装甲缝下有暗色内骨骼与内部机械
- 表面：程序化磨损贴图（划痕/掉漆/积灰）+ 清漆车漆 + 影棚环境反射
